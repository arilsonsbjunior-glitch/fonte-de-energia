Decreto dos data centers deve sair ainda em novembro

Luz10 de novembro de 2026Fonte: TAG Law

O regime especial para data centers, o Redata, deve ser regulamentado até o fim do mês. Um dos pontos em debate é se essas empresas terão que contratar energia nova para abastecer as próprias instalações.

O que isso quer dizer

Data centers são prédios cheios de servidores que guardam e processam dados, inclusive para inteligência artificial. Eles consomem muita energia, o tempo todo. O Redata é um regime especial que dá incentivos fiscais para atrair esses investimentos ao Brasil.

O decreto vai definir as regras na prática. Um ponto em discussão é se os data centers terão que trazer energia nova para o sistema, em vez de só usar a que já existe, para não pesar na conta de todo mundo.
